# Security Policy

## Supported versions

Security fixes are applied to the current `0.3.x` line on the default branch.
Older snapshots are not supported.

## Report a vulnerability

Email `security@arcanada.ai` or use GitHub's private vulnerability reporting for
this repository. A PGP key for the reporting address is published through
`keys.openpgp.org`. Do not open a public issue for an unpatched vulnerability,
and do not include credentials, tokens, tenant data, or exploit details in
public discussions.

Include the affected route or component, reproduction conditions, impact, and
any suggested mitigation.

## Response and disclosure timeline

- We acknowledge reports within 72 hours.
- We complete initial triage within 7 days.
- Critical and high-severity vulnerabilities are fixed within 90 days.
- Medium-severity vulnerabilities are fixed within 180 days.
- Low-severity vulnerabilities are addressed on a best effort basis.

We use coordinated disclosure. Public disclosure occurs within 14 days after a
fix or 120 days after the report, whichever is sooner. We coordinate timing
with the reporter and affected downstream users when practical.
