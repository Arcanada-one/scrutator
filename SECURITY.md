# Security Policy

## Supported versions

Security fixes are applied to the current `0.3.x` line on the default branch.
Older snapshots are not supported.

## Report a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a
public issue for an unpatched vulnerability and do not include credentials,
tokens, tenant data, or exploit details in public discussions.

Include the affected route or component, reproduction conditions, impact, and
any suggested mitigation. The maintainers will acknowledge the report,
coordinate a fix, and publish disclosure details after affected deployments
have been updated.
